# Contract: Surface & Artwork Guarantees

What each rendering surface must guarantee after this feature, and what the manifest must declare.
These are the assertions the verification harness encodes.

## Every surface

| Guarantee | Assertion |
|---|---|
| Zero console errors on load | collected `console` + `pageerror` log is empty |
| No text below 12px | every text-bearing element's computed `font-size` parses `>= 12` |
| No horizontal overflow | `documentElement.scrollWidth <= clientWidth` |
| Tokens resolve | `getComputedStyle(root).getPropertyValue('--accent')` is non-empty |
| No legacy palette | computed background of `body` is the new `--bg`, not `#0d1117` |
| Fonts resolve locally | no network request to a font CDN; `document.fonts` resolves or falls back cleanly |

## Extension pages

| Page | Extra guarantee |
|---|---|
| `sidepanel.html` | assertions hold at **several widths**, not just default — the panel is user-resizable. Close control present, activates `window.close()`, and is **not** an X in the top-right (Chrome's own close lives there) |
| `popup.html` | stays a thin launcher at 320px; no brief rendering added |
| `options.html` | restyled only; sign-in, client ID, redirect URI, provider fields all still present |

Extension URLs are stable because `manifest.key` pins the ID:

```
chrome-extension://kopmahhdddlcipdggmgldkofjpneeboa/{sidepanel,popup,options}.html
```

## Manifest

Required after this feature:

```jsonc
"action": {
  "default_popup": "popup.html",
  "default_title": "BD Lead AI",
  "default_icon": { "16": "icons/16.png", "48": "icons/48.png", "128": "icons/128.png" }
},
"icons": { "16": "icons/16.png", "48": "icons/48.png", "128": "icons/128.png" }
```

`action.default_icon` is the missing key — without it the toolbar and the side-panel header fall
back to a generated placeholder even though top-level `icons` is set.

**Must not change**: `version` (generated by `scripts/sync_versions.py`, use `make bump-patch`) and
`key` (pins the extension ID that the OAuth redirect URI depends on).

## Artwork

| Asset | Requirement |
|---|---|
| `extension/icons/16.png` | 16×16, real artwork, legible mark, no text |
| `extension/icons/48.png` | 48×48, real artwork |
| `extension/icons/128.png` | 128×128, real artwork |
| `web/public/favicon.svg` | the same mark, replacing template art |

"Real artwork" is testable as: decoded dimensions match the declared size, and file size is far above
the near-blank baseline it replaces (428 / 175 / 95 bytes for 128 / 48 / 16). A gradient-filled
128×128 mark lands in the multi-kilobyte range — the verified sample was 6330 bytes.

## Unchanged contracts

This feature touches **no** API contract. `/api/leads/enrich` and `/api/leads/push` keep their
request and response shapes, and the preview object keeps `company_snapshot`,
`personalized_opener`, and `follow_ups[3]{title, description, due_in_days, rationale}`.

Fields the design depicts but the contract does not supply are rendered `inert` (see
[data-model.md](../data-model.md)) — never fabricated, and never a reason to widen the contract
inside this feature.
